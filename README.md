# react-eco-store
Eco-Friendly Online Store site:  *[react-eco-store](https://react-eco-store.netlify.app/)*

## Sustainable E-Commerce Platform Development

✅ Full-Cycle Development: Designed and deployed

The eco-store platform was built entirely from scratch, featuring secure user authentication with server-side data validation to ensure GDPR-compliant privacy protections.

🚀 Modern Tech Stack

Backend: Express.js framework for scalable API development
Build Tool: Vite for ultra-fast frontend tooling
State Management: Redux Toolkit for efficient product data handling
Database: Aiven.io PostgreSQL cluster for sustainable data storage

### Whole stack:
* ReactJS 19
* TypeScript
* Redux Toolkit
* React Router v6
* Axios + Fetch
* Husky + Eslint
* TailwindCSS + ShadCN: *(rapid and stylish UI development)* 
* React Hook Form + Zod: *(form validation)* 
* React Hooks
* react-hot-toast: *(user notifications)* 
* Prettier
* CSS-Modules / SCSS
* React Content Loader
* React Pagination
* Lodash.Debounce
* lucide-react: *(icon library)* 
* JSON Web Token
